# ♠ پوکر تگزاس با مربی (Texas Hold'em Coach)

بازی پوکر تگزاس هولدم به زبان فارسی، همراه با حریف‌های کامپیوتری و مربی آموزشی.
یک فایل HTML تکی است و به هیچ سرور، بسته یا ابزار ساختی نیاز ندارد.

## امکانات
- بازی با ۳ حریف کامپیوتری، بلایندهای ۱۰ و ۲۰ و ۱۰۰۰ ژتون برای هر نفر
- فولد، چک، کال، رِیز با اسلایدر و آل‌این، همراه با سایدپات
- مربی آموزشی:
  - شانس برد به روش شبیه‌سازی
  - رتبه‌بندی گزینه‌ها از «خیلی عالی» تا «اشتباه» با دلیل ساده
  - تحلیل میز و دست، کارت‌های خوب (اوت) و دراوها
  - توضیح اصطلاحاتی که همان لحظه روی صفحه هستند
- دکمه‌ی «قواعد» برای توضیح کامل قوانین
- تم روشن و تیره خودکار

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
1. مخزن (repository) تازه بسازید و فایل‌های این پوشه را آپلود کنید.
2. به **Settings ← Pages** بروید.
3. در بخش Source گزینه‌ی **Deploy from a branch** و شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید.
4. بعد از چند دقیقه بازی در آدرس `https://USERNAME.github.io/REPO/` در دسترس است.

## نکته
فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ اگر آفلاین باشید، فونت پیش‌فرض سیستم استفاده می‌شود.
